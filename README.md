# Andrés Sevilla — Portfolio

Astro + Tailwind CSS v4, deployed to GitHub Pages.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs dist/
```

- Content (all projects, per tab): `src/data/projects.ts`
- Cement look (slabs, frames, carved text): `src/styles/global.css`
- Media: `public/media/` (prefer short looping .mp4 over .gif)
